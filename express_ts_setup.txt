# 🚀 Express.js + TypeScript + ESLint + Prettier (Yarn Setup Guide)

## 🧱 1. Initialize the project
```bash
yarn init -y
```

## 📦 2. Install Express
```bash
yarn add express
```

## 🧰 3. Install TypeScript and types
```bash
yarn add -D typescript ts-node @types/node @types/express
```

## ⚙️ 4. Initialize TypeScript configuration
```bash
npx tsc --init
```
Update your **tsconfig.json** like this:
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "CommonJS",
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  }
}
```

## 📁 5. Project structure
```
project/
├── src/
│   └── index.ts
├── package.json
└── tsconfig.json
```

## ✏️ 6. Example `src/index.ts`
```ts
import express, { Request, Response } from "express";

const app = express();
const port = 3000;

app.get("/", (req: Request, res: Response) => {
  res.send("Hello, Express + TypeScript!");
});

app.listen(port, () => {
  console.log(`🚀 Server running at http://localhost:${port}`);
});
```

## 🧩 7. ESLint + Prettier Setup
Install dependencies:
```bash
yarn add -D eslint prettier eslint-config-prettier eslint-plugin-prettier @typescript-eslint/eslint-plugin @typescript-eslint/parser
```

### Create `.eslintrc.json`
```json
{
  "env": {
    "es2021": true,
    "node": true
  },
  "extends": [
    "eslint:recommended",
    "plugin:@typescript-eslint/recommended",
    "plugin:prettier/recommended"
  ],
  "parser": "@typescript-eslint/parser",
  "parserOptions": {
    "ecmaVersion": "latest",
    "sourceType": "module"
  },
  "plugins": ["@typescript-eslint", "prettier"],
  "rules": {
    "prettier/prettier": [
      "error",
      {
        "endOfLine": "auto"
      }
    ]
  }
}
```

### Create `.prettierrc`
```json
{
  "semi": true,
  "singleQuote": false,
  "trailingComma": "all",
  "printWidth": 100,
  "tabWidth": 2,
  "endOfLine": "auto"
}
```

### Create `.eslintignore` and `.prettierignore`
```
dist
node_modules
```

## 🧹 8. Update package.json scripts
```json
"scripts": {
  "start": "node dist/index.js",
  "dev": "ts-node src/index.ts",
  "build": "tsc",
  "lint": "eslint 'src/**/*.{ts,tsx}'",
  "lint:fix": "eslint 'src/**/*.{ts,tsx}' --fix",
  "format": "prettier --write 'src/**/*.{ts,tsx,json,md}'"
}
```

## 🚀 9. Run Commands
Run development server:
```bash
yarn dev
```

Build for production:
```bash
yarn build
```

Run linter:
```bash
yarn lint
```

Fix lint issues automatically:
```bash
yarn lint:fix
```

Format code with Prettier:
```bash
yarn format
```

---
✅ Done! You now have a **fully configured Express + TypeScript + ESLint + Prettier** setup using Yarn.
